title: Navigation links in generated App screens
description: Create and edit controls expose their registered screen routes.
---

Newly generated App screens use `NxLinkButton` to open registered create and edit routes. The Agent can open those forms from the current screen. Existing Apps can use the same links for navigation and keep saving as a separate action.

[Screen navigation guide](https://developers.nexia.to/docs/platform-extensions-add-navigation) · [Devtools source for this version](https://github.com/nexia-cloud-os/devtools/tree/v0.2.21)
