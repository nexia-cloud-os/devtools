리소스 생성기와 새 앱 템플릿이 Inspector·화면 등록에 하나의 리소스 계약 맵을 공유합니다. 화면 모듈은 계속 지연 로딩됩니다. 재생성 시 인식 가능한 기존 생성 등록 코드를 갱신하고 사용자 정의 진입점은 보존합니다. 기존 앱은 이 Devtools 버전으로 진입점을 재생성할 수 있으며 런타임 SDK API 변경은 필요하지 않습니다.

## 사용 방법

- [Nexia CLI](https://developers.nexia.to/ko/docs/getting-started-cli)
- [Resource 만들기](https://developers.nexia.to/ko/docs/building-apps-create-a-resource)
- [공개 CLI 문서](https://github.com/nexia-cloud-os/cli/blob/main/README.md)
