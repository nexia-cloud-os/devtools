앱·리소스 생성 안내에서 `nexia create app`, `nexia make resource`, `nexia connect`와 프로젝트 `nexia dev`를 사용합니다. CLI 0.2.0-alpha.1 이상을 사용하세요. 이전 명령 이름은 별칭으로 지원하지 않습니다. 기존 앱 파일은 자동 변경하지 않으며 런타임 SDK 요구사항도 그대로입니다.
