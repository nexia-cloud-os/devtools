---

새 앱은 React SDK 0.8.2 이상으로 빌드하며 공통 프런트엔드 성능 지침을 포함합니다. 생성기와 React SDK 검증에서 실제 생성 앱을 빌드하여 의존 파일 사전 로딩, 화면 지연 로딩, 호스트 공통 라이브러리 분리를 확인합니다.

`nexia setup --devtools`로 생성기를 갱신하세요. 기존 앱 파일은 덮어쓰지 않습니다. 실제 설치되는 빌드 SDK를 갱신하고 `nexiaAppConfig`를 유지한 뒤 다시 빌드·게시해야 합니다. 공유 런타임 이미지 구성은 이미 검증된 파일을 다시 빌드하지 않습니다. 런타임 호환 요구사항과 PHP 계약은 변경되지 않습니다.
