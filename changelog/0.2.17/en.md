## App agent guidance

Newly generated Apps route coding assistants to the relevant task guides and prioritize public host components for screens. Existing App instructions remain developer-owned and are not overwritten. See [working with a coding assistant](https://developers.nexia.to/docs/getting-started-agent-assisted-development) and the [generator source](https://github.com/nexia-cloud-os/devtools/blob/main/stubs/package-app/agents.stub).
