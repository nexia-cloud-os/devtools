New Apps declare an editable empty overview dashboard and require PHP SDK ^0.10.22. Use a matching Core and App runtime. Existing Apps are unchanged. See the [dashboard guide](https://developers.nexia.to/docs/platform-extensions-add-dashboard-widget) and [generator source](https://github.com/nexia-cloud-os/devtools/blob/main/src/Commands/MakePackageApp.php).
